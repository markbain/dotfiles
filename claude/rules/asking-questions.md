## Asking questions

When you need more than one answer from me, run the `/grill-me` skill rather than
asking ad hoc. One question at a time, each with your recommended answer, walking
down the dependency tree so earlier answers shape later questions.

This applies whenever a task has several open decisions - scoping a feature,
planning an approach, resolving ambiguity in a brief, designing a tool. A single
isolated question needs no ceremony; two or more means grill me.
