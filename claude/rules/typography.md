## Typography

Never use m-dashes (—) in **client communications**: emails, proposals, reports, invoices,
client-facing web copy, PDFs, social posts, and anything else a client or the public reads.
Use a single hyphen (-) if a dash is needed there, and use it sparingly. M-dashes are not on a
standard keyboard and look out of place in that context.

This rule does not govern internal work - code, comments, commit messages, internal docs and
ADRs. There, match whatever convention the surrounding file set already uses rather than
imposing hyphens on it. Most existing ADR titles use an m-dash, for example, so a new ADR
should too.
